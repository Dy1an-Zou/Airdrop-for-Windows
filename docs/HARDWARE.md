# 硬件与运行边界

## 已验证的组合（历史实机记录）

作者的专用 MT7925 PCIe（硬件 ID `PCI\VEN_14C3&DEV_7925&SUBSYS_60001A3B&REV_00`）、r36 内核和无线用户态组件、r39 AWDL 组件完成过 iPhone 照片接收。2026-10-16，同一套配置上的已安装 0.2.0 又由用户确认向 iPhone 成功发送一张图片，运行日志记录 accepted 和 sent。两个方向分别有实机结果，均仅覆盖这套配置。

驱动 INF 面向 Windows x64 build 26100 及以上，KMDF 1.33。它注册为专用系统设备，不提供普通 Windows Wi-Fi 网络适配器。设备运行时由用户态程序控制原始无线帧，经 Wintun `awdl0` 接口交给接收程序。

默认无线配置为信道 6、20 MHz、现有固件监管限制。不得仅根据芯片同名推断其他 OEM、子系统 ID、固件或天线设计可以直接使用。

## 0.2.4 分支新增：RTL8852CE 候选

`PCI\VEN_10EC&DEV_C852` 已增加独立后端和安装器检查，使用 winawdl v0.3.0 的配套原生组件。
本项目没有 RTL8852CE 实物，尚未验证发现、传输、关停和再次开启。它不是 MT7925 实测结论的延伸。
准备条件和反馈步骤见 [RTL8852CE.md](RTL8852CE.md)，实际离线结果见 [RTL8852CE-VALIDATION.md](RTL8852CE-VALIDATION.md)。

## 0.2.3 的设备识别与运行要求

0.2.3 的 `app/src/Xiatiao/RadioHost.cs` 通过 `SupportedHardware` 限定上述完整硬件 ID，再自动读取本机唯一匹配设备的实例。开发者不再手填作者电脑的设备实例。没有匹配设备、出现多个匹配设备，或本次连接中的实例发生变化时，助手会停止处理；不会改选其他网卡。

应用仍要求这块专用设备的 `mt7925_bringup` 实验驱动已经正常运行，设备状态正常且没有问题代码。`DriverSha` 和 `Pinned` 保留已验证组合的固定摘要；运行前同时检查安装位置、文件权限、完整包清单、后端文件摘要、驱动位置和驱动摘要。自动识别实例没有扩大支持的硬件或驱动范围。

0.2.3 安装器检查 **Windows x64 build 26100 及以上、.NET Desktop Runtime 10 x64、唯一匹配的专用网卡和固定版本的实验驱动**。当前固定驱动 SHA-256 为：

```text
938148d69b14c911c18c4c7a9ef00703ad5625e46d876143b8f887df6762aafb
```

重新构建原生组件或重新签名驱动会改变摘要，需要验证新的实际组合，并同步应用和安装器中的摘要约束。仅从公开源码编译出新驱动，不代表它能通过当前发行包的版本检查。

## 驱动和签名

仓库不含已签名驱动、签名私钥或测试证书。`driver/mt7925/build_driver.py` 生成未签名候选，不安装它。0.2.3 单 EXE 安装器只部署应用及配套运行文件，不安装 / 替换驱动、不改变测试签名或其他安全设置、不自动重启。驱动签名和配置仍由开发者单独完成，安装步骤见 [INSTALL.md](INSTALL.md)。

作者实机使用实验驱动和自行配置的测试签名环境。公开部署所需的签名、Windows 安全配置兼容性与驱动分发路径尚未完成。内核移植仍可能导致系统崩溃，不能把它当作通用消费级驱动。

## 应用权限

窗口和文件收发进程以普通用户身份运行；安装后的受限无线助手由计划任务以当前用户的提升权限运行。它只接受已安装的同用户应用发来的启动/停止请求，不接收任意命令或程序路径。安装与卸载要求当前账户属于管理员组，并在管理员确认时保持同一账户。

接收开启期间使用仅绑定 `awdl0` 和随包 Python 程序的 TCP 8771、UDP 5353 防火墙规则，范围为链路本地 IPv6。关闭接收会停止对应无线进程、接口与规则；普通关闭窗口只是隐藏到托盘，完全退出请使用托盘菜单。

## 未验证范围

未验证其他网卡、跨电脑安装、其他信道、多个收发会话并发、所有 Apple 机型、所有 iOS/macOS 版本、所有文件类型或长期连续运行。公开源码副本未另行构建。「仅限联系人」、验证码配对和 30 天临时联系人当前不支持。

0.2.0 的双向图片结果保留为上述历史记录。0.2.3 的自动识别、界面及安装器离线验证结果已分别记录于 [构建与验证说明](BUILD.md) 和 [安装说明](INSTALL.md#验证范围)；这些结果不代表新电脑已完成安装验收。
