# Airdrop for Windows 0.2.4 — RTL8852CE Community Preview

作者 / Author: **Dy1an-Zou** · **Pre-release / 实验预览版**

## 中文

这一版迈出了扩展网卡兼容性的第一步：新增 **Realtek RTL8852CE PCIe** 的无线后端接入和专用安装包，保留现有的收发文件、托盘、自启动、文件管理和中英界面。

**这是供社区测试的候选版本，不是已经验证成功的 RTL8852CE 支持。作者目前没有这张网卡，本项目尚未在 RTL8852CE 上进行实机测试。** 欢迎有对应硬件、愿意准备实验环境的朋友反馈结果。

### 兼容性声明

| 硬件 | 本次状态 |
| --- | --- |
| **RTL8852CE PCIe**，`PCI\VEN_10EC&DEV_C852` | 新增接入，构建及离线检查通过；**设备发现、收发和稳定性均待实机验证**。不同厂商的 SUBSYS / OEM 版本没有逐一测试。 |
| **MT7925**，`PCI\VEN_14C3&DEV_7925&SUBSYS_60001A3B&REV_00` | 保留[原 0.2.3 下载](https://github.com/Dy1an-Zou/Airdrop-for-Windows/releases/tag/v0.2.3)。历史双向图片传输实测来自作者的 0.2.0 配置，不代表所有 MT7925 或 0.2.4 都已通过实机验证。 |
| RTL8852AE / RTL8852BE、Realtek USB、Intel、Broadcom，以及其他未列明的网卡 | **不在本次新增支持范围内**；芯片名称相似不代表可以使用这个安装包。 |

**RTL8852CE 安装包不能覆盖升级正在使用的 MT7925 版本。** 两种后端使用不同的运行组件，安装器会拒绝跨后端更新。

### 安装前需要准备

- Windows 11 x64，系统构建 **26100 或更新版本**；.NET Desktop Runtime **10 x64** 和 Microsoft Visual C++ **2015–2022 x64** 运行库。
- 一块专用 RTL8852CE，以及另一条日常上网连接。绑定实验驱动后，这块卡不再承担普通 Windows Wi-Fi 联网。
- 预先配置 [winawdl v0.3.0](https://github.com/raph559/winawdl/releases/tag/v0.3.0) 对应的 `winawdl_regproxy` 实验驱动，以及运行账户的「锁定内存页」权限（`SeLockMemoryPrivilege`）。详细步骤与版本要求见[测试指南](https://github.com/Dy1an-Zou/Airdrop-for-Windows/blob/v0.2.4/docs/RTL8852CE.md)。

安装包只部署应用和配套运行文件，**不会安装或替换网卡驱动、修改测试签名策略、授予上述权限或自动重启**。仅使用原厂 Realtek 驱动无法直接启用这条实验路径。实验驱动和 DMA 操作仍有系统崩溃或需要重启的风险，请保留原厂驱动的恢复方式。

### 已检查与尚未验证

- 已完成桌面程序和安装器编译；后端 **63 项**、现有助手 **49 项**、安装配置 **30 项**、安装器隔离样例 **39 项**离线检查通过；7 个定向反例均被捕获。语言检查、Windows PowerShell 5.1 兼容检查及安装包 389 个文件的内容校验通过。
- **尚未执行：**RTL8852CE 的真实安装 / 更新 / 卸载、Apple 设备发现、双向文件传输、关闭后重新开启、睡眠唤醒、长时间运行及不同 OEM 硬件测试。离线结果和上游项目的结果不能代替本软件的实机验证。
- RTL 后端沿用上游的 **5 GHz 信道 149、80 MHz** 配置；地区信道可用性和不同硬件的射频表现未验证。正常退出也不提供独立的 DMA 停止状态读回验证。
- 尚未验证所有 iPhone / iPad / Mac、iOS / iPadOS / macOS 版本和文件类型。「仅限联系人」、验证码配对及 30 天临时联系人功能当前不支持；初次测试请使用「所有人，10 分钟」。

### 下载与反馈

- **`Airdrop-for-Windows-0.2.4-RTL8852CE-Preview-Setup-x64.exe`**：仅用于已配置上述实验环境的 RTL8852CE。
- **`Airdrop-for-Windows-0.2.4-RTL8852CE-Source.zip`**：项目源码和四份对应版本的上游原生组件源码归档。GitHub 自动生成的 Source code 归档不包含这四份额外归档，可用仓库脚本获取。
- `START-HERE.md`、`VALIDATION.json`、`SHA256SUMS.txt`：使用入口、验证范围和文件校验值。

测试时先尝试一张普通图片，依次记录发现电脑、Apple → Windows、Windows → Apple、关闭重开是否成功。请在 [Issues](https://github.com/Dy1an-Zou/Airdrop-for-Windows/issues) 附上网卡完整硬件 ID、Windows 版本、Apple 设备及系统版本、失败阶段；分享日志前去除个人信息，不上传私钥或私人文件。

## English

This release takes the first step toward broader adapter compatibility: a **Realtek RTL8852CE PCIe** backend and a dedicated installer, while retaining file sending and receiving, tray operation, startup, file management, and the Chinese / English interface.

**This is a community test candidate, not verified RTL8852CE support. The author does not currently own this adapter, and this project has not tested the release on RTL8852CE hardware.** Feedback from testers with the matching hardware and an experimental setup is welcome.

### Compatibility statement

| Hardware | Status in this release |
| --- | --- |
| **RTL8852CE PCIe**, `PCI\VEN_10EC&DEV_C852` | Backend integration added; builds and offline checks passed. **Discovery, transfers, and stability still require hardware testing.** Vendor-specific SUBSYS / OEM variants have not been individually tested. |
| **MT7925**, `PCI\VEN_14C3&DEV_7925&SUBSYS_60001A3B&REV_00` | The [existing 0.2.3 download](https://github.com/Dy1an-Zou/Airdrop-for-Windows/releases/tag/v0.2.3) remains available. Historical bidirectional image transfers were tested on the author's 0.2.0 setup; this does not establish hardware validation for every MT7925 or for 0.2.4. |
| RTL8852AE / RTL8852BE, Realtek USB, Intel, Broadcom, and other unlisted adapters | **No support is added for these adapters.** Similar chip names do not imply compatibility with this installer. |

**Do not install the RTL8852CE package over a working MT7925 installation.** The backends use different runtime components, and the installer rejects updates that change the backend.

### Prerequisites

- Windows 11 x64 **build 26100 or later**, **.NET Desktop Runtime 10 x64**, and **Microsoft Visual C++ 2015–2022 Redistributable x64**.
- A dedicated RTL8852CE and a separate internet connection. The adapter cannot provide ordinary Windows Wi-Fi connectivity while bound to the experimental driver.
- The matching `winawdl_regproxy` experimental driver from [winawdl v0.3.0](https://github.com/raph559/winawdl/releases/tag/v0.3.0), configured in advance, plus **Lock pages in memory** (`SeLockMemoryPrivilege`) for the account running the helper. See the [test guide](https://github.com/Dy1an-Zou/Airdrop-for-Windows/blob/v0.2.4/docs/RTL8852CE.md) for the preparation and pinned-version requirements.

The installer deploys the app and runtime files. **It does not install or replace the adapter driver, change test-signing policy, grant that privilege, or reboot Windows.** The stock Realtek driver alone cannot enable this experimental path. Experimental driver and DMA operations can cause system crashes or require a reboot; retain a way to restore the original driver.

### Checks completed and remaining limits

- Desktop app and installer compiled. Offline checks passed: **63** backend checks, **49** existing helper checks, **30** installer-profile checks, and **39** isolated installer fixtures. All 7 directed fault-injection cases were detected. Language checks, Windows PowerShell 5.1 checks, and verification of the installer's 389-file payload passed.
- **Not performed:** actual RTL8852CE installation / update / removal, Apple-device discovery, transfers in either direction, shutdown/restart, sleep/wake, extended operation, or OEM hardware testing. Offline results and upstream results are not hardware acceptance of this application.
- The RTL backend retains the upstream **5 GHz channel 149 / 80 MHz** configuration. Regional channel availability and RF behavior across hardware variants are unverified. Normal shutdown does not provide an independent DMA-quiescence readback.
- Compatibility with all iPhone / iPad / Mac models, iOS / iPadOS / macOS versions, and file types is unverified. **Contacts Only, verification-code pairing, and 30-day temporary contacts are not implemented.** Use **Everyone for 10 Minutes** for initial testing.

### Downloads and feedback

- **`Airdrop-for-Windows-0.2.4-RTL8852CE-Preview-Setup-x64.exe`**: for RTL8852CE with the experimental environment above already prepared.
- **`Airdrop-for-Windows-0.2.4-RTL8852CE-Source.zip`**: project sources and four pinned corresponding-source archives for native upstream components. GitHub's automatically generated Source code archives do not include those four additional archives; the repository's fetch script can retrieve them.
- `START-HERE.md`, `VALIDATION.json`, and `SHA256SUMS.txt`: getting started, validation scope, and file checksums.

Start with one ordinary image. Report PC discovery, Apple → Windows, Windows → Apple, and shutdown/restart separately. When opening an [issue](https://github.com/Dy1an-Zou/Airdrop-for-Windows/issues), include the full adapter hardware ID, Windows version, Apple device / OS, and the failing stage. Remove personal information from logs and never upload private keys or private files.
